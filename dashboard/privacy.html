Ten-Four HQ Privacy Policy

Last updated: November 23, 2026

Ten-Four HQ is a private, internal tool that its owner uses to run the Ten-Four Tapes YouTube channel and Facebook page. It is not offered to the public, and no one other than the owner signs in to it.

Google account data

Ten-Four HQ accesses only the owner's own Google account, for these purposes:

  • Gmail (send, read-only): to send public records requests written by the tool and to read the replies to those requests.
  • YouTube (upload, read-only) and YouTube Analytics (read-only): to upload the owner's videos to the owner's channel and to read the channel's own performance numbers.

It does not access any other person's Google account. Ten-Four HQ's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

Ten-Four HQ uses YouTube API Services to upload videos to, and read analytics for, the owner's own YouTube channel. By using Ten-Four HQ you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The YouTube data Ten-Four HQ uses is limited to the owner's own channel: the videos it uploads, their titles, descriptions and thumbnails, and the channel's own view, watch-time and subscriber numbers. No other user's YouTube data is accessed, stored or shown.

What we store

Request emails, reply status, video plans, channel metrics and operating logs are stored in the owner's private database. OAuth tokens are stored as encrypted secrets and are never shared.

What we don't do

  • We do not sell, rent or share Google user data with anyone.
  • We do not use Google user data for advertising.
  • We do not use Google user data to train AI models.

Keeping and deleting data

YouTube channel metrics are kept for up to 30 days and refreshed from the API; older YouTube API data is deleted or refreshed so that nothing stored is more than 30 days old. All stored YouTube and Google data for the account is deleted within 7 days after access is revoked, or on request.

Removing access

The owner can revoke Ten-Four HQ's access at any time at myaccount.google.com/permissions (Google security settings page). Revoking access stops all YouTube and Gmail use immediately, and stored data is then deleted as described above.
